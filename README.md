# PM2.5 Explorer

ระบบสำรวจคุณภาพอากาศ PM2.5 ของประเทศไทย (รายวิชา 1145100 Data Science Toolbox)

## วิธีติดตั้ง

### ด้วย conda (Miniforge)
```bash
conda env create -f environment.yml
conda activate dstoolbox
```

### หรือด้วย uv
```bash
uv sync
```
